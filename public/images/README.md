# 이미지 교체 안내

- `office-hero-1.jpg`, `office-hero-2.jpg`: 이전 켄번스 히어로 시안 보관용이며 현재 화면에서는 사용하지 않습니다.

- 대표·고문 사진은 `src/pages.tsx`의 `PortraitPlaceholder`를 로컬 이미지로 교체합니다.
