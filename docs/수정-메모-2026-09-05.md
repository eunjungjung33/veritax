- 수정 전: 존재하지 않는 `/assets/*.js` 요청에도 홈페이지 HTML을 HTTP 200으로 응답하고, 해당 잘못된 응답에 1년 캐시(`immutable`)를 지정했습니다. 존재하지 않는 `/images/` 사진도 HTML 200으로 응답했습니다.
- 수정 후: `/assets/`와 `/images/` 아래 파일이 없으면 HTTP 404 및 `no-store`로 응답하여 잘못된 파일 응답의 장기 저장을 막습니다.
- 일반 페이지 경로의 SPA 처리는 유지했습니다.
