# 새 흰색 로고 적용

- 제공된 Photo 1.jpg의 검은 배경을 Python/Pillow로 투명화하고 헤더와 푸터에 공통 적용했습니다. 원본 첨부파일은 수정하지 않았습니다.
- 새 파일: public/images/jej-logo-white.png (1280×209 RGBA). JPEG 배경 잡음을 제거하고 가장자리의 검은 매트를 보정했습니다.
- 밝은 글자에 불필요한 기존 흰색 외곽 효과를 제거했습니다. 가로형 비율에 맞게 헤더 로고 폭만 반응형으로 조정했습니다.
- 재생성: python scripts/prepare-white-logo.py INPUT_JPEG (Pillow 필요).
- 로컬 검증: 테스트 35개와 빌드 통과, 실제 390px/1440px 헤더·푸터·모바일 메뉴 확인, 가로 넘침 및 런타임 예외 0건.
- 이 기록은 푸시 전 검증 시점 기준입니다. 배포 결과는 작업 완료 메시지로 보고합니다.
